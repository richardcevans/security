# DeepSec MCP Traceability

| Lab | Scope |
| --- | --- |
| Lab 1: Import the ADB OCI IAM Environment | Consume the prerequisite environment without altering it, then prove the direct GenAI OCI IAM-to-ADB baseline against the same ADB. |
| Lab 2: Connect MCP Server Tools | Create and validate the Database Tools connection, MCP server, and built-in SQL toolset only after the GenAI baseline gate passes. |
| Optional Lab 2: Connect Cursor | Register and connect an external MCP client. |
| Lab 3: Review and Clean Up MCP Resources | Remove only MCP resources created by this workshop. |

Database and identity security configuration is traced to the ADB OCI IAM
workshop and is intentionally out of scope here.
