# DeepSec MCP Traceability

| Lab | Scope |
| --- | --- |
| Lab 1: Import the ADB OCI IAM Environment | Consume the prerequisite environment without altering it. |
| Lab 2: Connect MCP Server Tools | Create and validate Database Tools connection, MCP server, and built-in SQL toolset. |
| Optional Lab 2: Connect Cursor | Register and connect an external MCP client. |
| Lab 3: Review and Clean Up MCP Resources | Remove only MCP resources created by this workshop. |

Database and identity security configuration is traced to the ADB OCI IAM
workshop and is intentionally out of scope here.
